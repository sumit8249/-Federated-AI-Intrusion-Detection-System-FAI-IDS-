1. Project Overview

A is a privacy-preserving cybersecurity framework where multiple organizations (clients) collaboratively train an intrusion detection model without sharing their raw network traffic data.

Instead of sending sensitive data to a central server, each client trains the AI model locally and sends only encrypted model parameters to a central aggregation server using Flower Federated Learning Framework.

Problem Statement

Traditional Intrusion Detection Systems require centralized collection of network traffic logs, creating:

Privacy risks.

High bandwidth usage.
Data ownership issues.
Compliance challenges.
This project solves these issues using Federated Learning.
Proposed Solution
Local IDS models train on each client's data.
Flower server aggregates weights using FedAv.
Global model improves after every training round.
Raw network packets never leave local device.

Federated Algorithm

FedAvg (Federated Averaging)

Steps:

Initialize global model.

Send global weights to clients.

Clients train locally.

Clients send updated weights.

Server averages weights.

Repeat for multiple rounds.
